# Contributing

Please open an issue describing the user problem before large changes. Keep pull requests focused and include a failing regression test followed by the fix.

Use only self-authored or clearly licensed test media/subtitles. Never commit personal study results, credentials, Cookies, API keys, model caches, full third-party transcripts or diagnostic logs. Preserve original caption words/provenance and label machine translations, clipped sentences and approximate timing honestly.

Do not add remote inference, microphone access, telemetry, billing, browser cookie extraction or a new external provider without an explicit proposal, privacy review and opt-in design. Maintain loopback host/origin/token checks and the isolated YouTube bridge.

Run the documented Python and JavaScript test suites. UI changes need keyboard, narrow-width, no-autoplay and safe text-rendering checks. Dependency/runtime/model licenses must accompany redistributable changes.
