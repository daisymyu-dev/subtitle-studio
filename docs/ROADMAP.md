# Roadmap and scope

## Public Beta

- Local-first Windows release, independently declared dependencies and Word export.
- Existing official-player/sentence/translation/shadowing workflow, single gold curated highlights and local sample pronunciation.
- Local known/saved expression state, library/progress, explicit single-word dictionary lookup.
- Open source, provenance, privacy boundaries and repeatable tests/build instructions.

## Next validation

Ask 10–20 target learners whether they can install unaided, finish one short learning session, choose a second video and return another day. Test a diverse authorized set of accents, subject domains and caption quality. Network/platform support is measured, not promised universally.

## Planned, not implemented guarantees

- General semantic vocabulary/idiom recommendations beyond the 24-expression starter library; local frequency candidates and explicit optional provider configuration, with known-term personalization and verified source spans.
- Rich spaced review and Anki export; editable translations retaining original provenance.
- Wider dictionary/local pronunciation coverage, configurable reliable translation providers and offline options.
- Signed installer, independent clean-VM certification and macOS/Linux installers.

No current promise of IELTS scoring, precise word-level timing, human-certified translations/pronunciation, arbitrary-video availability, cloud sync, hosted multi-user service or paid subscriptions. These are separate product and security decisions.
