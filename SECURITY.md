# Security policy

This prerelease supports only single-user loopback operation. Do not deploy the Python server as a public multi-user service or disable its host/origin/token checks.

Please use the repository's **Security → Report a vulnerability** private reporting option when available. If unavailable, open an issue containing only a request for a private reporting channel—never publish secrets, personal caption files or exploit-ready private data. Public Beta has no guaranteed response SLA.

Relevant boundaries: fixed supported video identities; local upload size limits; exact static/audio routes; per-job media tickets; isolated official-player origin; validated retained paths and exclusive Word Desktop writes. No automatic Cookies, arbitrary proxy URL, paid API or cloud audio upload is supported.

Release archives are not code-signed. Verify origin and SHA-256; do not disable OS warnings or grant unnecessary administrator rights. Security fixes may be released as new prereleases rather than automatic updates.
